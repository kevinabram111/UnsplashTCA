# 📷 Picsum Photo Feed App (SwiftUI + TCA)

A lightweight, scalable SwiftUI app that fetches and displays images from the [Picsum Photos API](https://picsum.photos/) using:

- 🧠 [The Composable Architecture (TCA)](https://github.com/pointfreeco/swift-composable-architecture) for state management
- 🌐 [Moya](https://github.com/Moya/Moya) for clean API abstraction
- 🖼 [Kingfisher](https://github.com/onevcat/Kingfisher) for smooth image loading and caching
- ⚡ SwiftUI for a declarative and modern UI

> ✨ Includes loading shimmer, pagination, pull-to-refresh, and Safari link support — all powered by a simple, scalable TCA setup.

## 🚀 Features

- ✅ SwiftUI with navigation and refresh support
- ✅ Unidirectional data flow with TCA
- ✅ Paginated photo loading from API
- ✅ Cached image loading with downsampling (Kingfisher)
- ✅ Pull-to-refresh with `refreshable`
- ✅ Loading shimmer effect with custom modifier
- ✅ Safari link on photo tap
